## 📖 About The Project

**FoxxyNime V2** is a web-based entertainment platform focused on anime streaming and digital comic reading.

The platform combines anime and comic discovery, content search, genre browsing, bookmarking, dedicated detail pages, video playback, and comic reading into one interface.

FoxxyNime V2 is designed with a modern interface and a responsive experience, with Telegram integration as an additional access point through its bot ecosystem.

The project is built using modern web technologies, with a focus on maintainability, performance, and user experience.

## ✨ Key Features

### 🎬 Anime Discovery
- Browse available anime catalogs.
- Explore anime information and details.
- Discover content through genre categories.
- Search for anime titles.
- Access dedicated anime detail pages.

### 📚 Manga & Comic Reader
- Browse available comic catalogs.
- Search for comic titles.
- Explore comic genres.
- Open dedicated comic detail pages.
- Read available comic chapters and pages.
- Navigate between reader pages.

### 🔎 Smart Content Search
- Search for anime and comics.
- Switch between different content types.
- View matching search results.
- Explore content through genre filters.

### ▶️ Video Player
- Dedicated video viewing interface.
- Episode navigation.
- Available video quality selection.
- Playback settings where supported by the selected source.
- Video source information and playback error handling.

Playback availability and supported controls may vary depending on the content provider.

### 🔖 Bookmark System
- Save favorite content.
- Access saved content from the Saved section.
- Store bookmarks locally using browser local storage.

### 📱 Telegram Integration
- Telegram bot integration.
- Telegram-related API endpoints.
- Designed to support access through the FoxxyNime Telegram ecosystem.

Telegram Mini App availability depends on the deployed bot configuration.

## 💻 Local Development

Want to explore or contribute to the project?

### 1. Clone the repository

```bash
git clone https://github.com/foxxyoffc/foxxynime-v2.git
```

### 2. Enter the project directory

```bash
cd foxxynime-v2
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Configure any required environment variables for the scraper and Telegram integration according to the application source code and deployment configuration.

Never publish API keys, bot tokens, database credentials, or other private configuration.

### 5. Start development server

```bash
npm run dev
```

### 6. Open the application

Visit:

```text
http://localhost:3000
```

### Production Build

```bash
npm run build
npm run start
```

## 🔐 Security & Privacy
